# Pemeriksaan Hak Aset dan Klaim

**Penting sebelum penjualan:** asal-usul dan hak distribusi ulang seluruh aset di repositori belum diaudit oleh paket otomatis ini. Berhasilnya build atau CI **bukan** bukti kepemilikan, lisensi, atau izin penjualan.

| Komponen | Tindakan sebelum penjualan |
|---|---|
| \`assets/images/hero-studio.webp\` | Temukan sumber/original, pemegang hak, bukti lisensi, izin *redistribution in a paid template*, dan aturan atribusi. Jika tidak jelas, ganti dengan gambar baru yang dimiliki/dilisensikan secara sah. |
| \`assets/favicon.svg\` | Hasil build mengubah inisial/warna. Periksa hak penggunaan dan orisinalitas komponen sumber. |
| Ilustrasi CSS portofolio | Tinjau desain dan pastikan tidak menjiplak karya pihak lain; verifikasi hak pemakaiannya. |
| Font sistem pada CSS | Tetap gunakan fallback legal; bila mengganti font, periksa lisensi web embedding dan redistribusi. |
| Konten proyek, ulasan, angka, dan identitas | Semuanya contoh fiktif; jangan gunakan sebagai klaim proyek atau hasil bisnis nyata. |
| Pustaka eksternal/alat build | Jika menambah dependency, cek ketentuan lisensi dan kerentanan secara terpisah. |

Rekomendasi: catat sumber, tanggal akuisisi, jenis hak, dokumen bukti, batas penggunaan, dan kebutuhan atribusi untuk tiap aset. **Tunda penjualan atau redistribusi berbayar sampai semua hak jelas.** Konten contoh tidak boleh dipresentasikan sebagai karya klien nyata.
