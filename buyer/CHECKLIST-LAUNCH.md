# Checklist Serah Terima dan Peluncuran

Gunakan checklist ini untuk setiap pelanggan. Jangan menyatakan situs siap produksi hanya karena tes otomatis hijau.

- [ ] Identitas dan informasi bisnis milik pelanggan telah diverifikasi; seluruh kata "demo" dan klaim fiktif telah dihapus/diterangkan.
- [ ] Hak penggunaan foto, ilustrasi, ikon, dan font ditinjau dan didokumentasikan.
- [ ] Proyek portofolio adalah pekerjaan nyata dengan izin penggunaan, atau jelas ditandai sebagai konsep fiktif.
- [ ] Nomor WhatsApp dan alamat email valid, milik pelanggan, dan diuji secara manual; jangan mengaktifkan kontak demo.
- [ ] Tombol, navigasi, FAQ, dan tautan diuji pada layar desktop serta ponsel.
- [ ] Warna dan seluruh kombinasi kontras diuji; aksesibilitas manual keyboard dan screen reader telah dicek.
- [ ] Metadata SEO, judul, gambar sosial, domain HTTPS, dan favicon benar.
- [ ] \`SITE_URL\` sama dengan origin HTTPS yang dipakai dan \`ENABLE_INDEXING=true\` hanya setelah konten benar-benar siap.
- [ ] Tautan preview/editor internal telah dihapus dari deployment bila tidak diperlukan; tidak ada informasi sensitif dalam file frontend.
- [ ] \`npm test\` dan \`npm run build\` berhasil pada konfigurasi pelanggan.
- [ ] Pemilik, DNS, biaya hosting/domain, backup, akses akun, serta prosedur update dan support disepakati.
- [ ] Pengujian website live dan sumber daya yang dimuat sudah dilakukan setelah deployment; jangan mengklaim deployment live dari hasil build saja.
- [ ] Dokumentasi panduan pembeli dan ketentuan layanan/lisensi yang disepakati sudah diserahkan.

**Pencatatan:** simpan tanggal, reviewer, dan versi paket dalam berita acara sederhana untuk setiap serah terima.
